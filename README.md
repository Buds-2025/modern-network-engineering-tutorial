# 现代网络工程基础

[在线学习](https://modern-network-engineering-tutorial.netlify.app/) · [GitHub公开仓库](https://github.com/Buds-2025/modern-network-engineering-tutorial)

面向零基础读者的静态中文网络入门教程，包含学习准备、18课正文与附录。通过生活场景、贴切比方、图解、命令与操作练习，帮助读者理解网络并验证自己的判断。

当前包含33幅图解、15张表格、35段代码或记录模板，以及15道可展开答案的检查题。各课提供操作、规划或判断练习，第18课安排综合实操与能力验收。

## 打开方式

直接双击`现代网络工程基础_零基础在线教程.html`或`index.html`。分享或迁移时请复制整个项目文件夹，保留`tokens.css`、`styles/`与`scripts/`的相对位置。

若电脑已安装Python，也可在项目目录运行：

```powershell
python -m http.server 4173 --bind 127.0.0.1
```

然后打开[本地教程](http://127.0.0.1:4173/)。仅绑定本机地址，按Ctrl+C停止。

本地阅读没有框架、构建步骤、npm依赖、远程字体或运行时CDN请求；正文与基础目录可离线使用。外部资料、镜像拉取和真实网络实验需要联网。

## 阅读功能

- 搜索：顶部放大镜、侧栏搜索，或Ctrl+K／⌘K。支持正文、提示、表格、命令和问答；Enter打开首项，方向键浏览，Esc关闭。
- 阅读：目录定位、当前章节提示、章节翻页、字号切换、深浅主题与上次阅读位置。阅读位置表示页面滚动位置，不代表已完成学习。
- 手机：目录支持Esc、遮罩关闭和键盘焦点约束。小屏顶部省略打印按钮，可通过浏览器菜单打印。
- 复制：仅复制`code`中的原文；浏览器权限不足时尝试兼容方式，失败后提供手动复制提示。
- 打印：桌面顶部打印按钮或浏览器打印；隐藏阅读工具并展开问答。也可在打印对话框中选择保存PDF。

主题、字号和阅读位置仅保存在当前浏览器本地。禁用存储时正文和交互仍可使用，但偏好不会保存。

## 内容维护

章节使用`ch0`至`ch18`与`appendix`作为固定锚点，小标题使用`chN-sM`。增加正文时应沿用标题层级，并同步维护图表编号和原始资料链接。

关键技术表述核查日期为2026年10月8日。正文针对常见配置提供入门模型，已明确双栈、代理、NAT、Docker网络模式和TLS等例外。实际部署仍应核对对应软件版本、地区规则与真实网络环境。

第18课基础网页实验需要Python 3，使用8000端口，仅服务`examples/lab-site/`。在项目目录运行：

```powershell
python -m http.server 8000 --bind 127.0.0.1 --directory examples/lab-site
```

然后在同一台电脑打开[实验网页](http://127.0.0.1:8000/)。按Ctrl+C停止；部分系统需把`python`替换成`python3`或`py -3`。本实验用于临时学习，不用于生产部署。

第14课实验需要Docker与Compose。请勿将示例密码、数据库或端口配置直接沿用到生产环境。镜像标签用于教学复现，不构成对具体版本长期可用性的保证。基础配置、DNS和浏览器观察练习不要求Docker。

第18课提供六项能力验收，要求独立完成操作并解释证据。读完并完成练习后，目标是能处理常见家庭和小型办公网络的入门任务；运营商路由、大型园区和生产集群仍需专项学习。

## 发布

Netlify使用`netlify.toml`中的命令：

```sh
node scripts/prepare-publish.mjs
```

该步骤无需安装npm依赖，只把明确列出的8个网页与示例文件复制到`public/`。Netlify发布目录为`public/`。它是生成目录，请修改原始文件后重新生成。

公开仓库仅提交教程源码、教学示例、说明文件与发布配置。本地审查记录、环境文件、部署凭据、缓存和测试产物通过`.gitignore`排除；发布脚本还检查常见个人路径及凭据特征。提交前仍应检查实际暂存清单。
